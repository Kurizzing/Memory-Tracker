# Memory Tracker

데일리 노트에 적은 공부 내용을 헤더 단위로 추적해서, 망각 주기에 맞춰 복습할 항목을 보여주는 개인용 Obsidian 플러그인.

## 사용법

데일리 노트(템플릿)에 두 헤더를 둔다.

```markdown
## 복습        ← 여기 아래에 ```memory-tracker``` 블록이 자동으로 들어감

## 학습
### 한국사                        ← 과목
* 최태성 심화강의 14, 15, 16강    ← 복습 항목 1개
	* 세부 메모                   ← 들여쓴 하위 목록은 항목에 포함 안 됨
### 영어
* 어휘끝 day5                     ← 복습 항목
* 천일문 day5                     ← 복습 항목
### 수학                          ← 목록이 없으면 과목 헤더 자체가 항목
```

## 복습 일정 (공부한 날 기준, 고정 — 기본값)

| 단계 | 시점 | 방식 |
|---|---|---|
| 다음 날 | +1일 | 흐름 인출, 다시 읽기 |
| 3일 후 | +3일 (금요일이어도 그대로) | 전체 인출(검은펜), 부족한 것 체크(빨간펜) |
| 복습일 · 이번주 | 공부한 날 이후 첫 목요일 | 흐름 인출 |
| 복습일 · 전주 | 그다음 목요일 | 전체 인출 |

목/금에 공부한 내용은 다음 주 진도로 취급된다(이후 첫 목요일 = 다음 주 목요일).

설정 → 일정 → 복습 주기에서 단계를 추가/삭제/순서 변경할 수 있다. 각 단계는 기준("N일 후" 또는 "N번째 복습일") + 값 + 방식(흐름/전체 인출)으로 정한다.

## 기능

- 사이드바 "오늘의 복습" 뷰 (날짜 이동 가능) / 코드블록 — 각각 설정에서 on/off
- ✅ 체크로 단계별 완료 → 공부한 날 노트의 항목 끝에 ✅ 표시 (완료한 단계 수만큼, 해제하면 지움, 설정에서 끄기 가능)
- 🚫 추적 금지 (설정의 추적 금지 목록에서 해제)
- 우클릭 → 이름 변경: 노트의 항목을 고치고 기록을 이어감
- 노트에서 항목 하나만 직접 고치거나 과목 헤더 이름을 바꿔도 기록 유지
- 설정: 추적 시작일, 부모 헤더(기존 노트에 일괄 적용 가능), 복습일 요일, 같은 날 겹침 합치기(기본 꺼짐), 밀린 복습 표시, 코드블록 헤더

## 개발

```bash
npm install
npm test        # 일정/파서 로직 테스트
npm run build
npm run deploy  # 빌드 후 <볼트>/.obsidian/plugins/memory-tracker 로 복사 (기본 볼트: C:/Obsidian Vault, OBSIDIAN_VAULT 또는 인자로 변경)
```

데이터(완료 기록, 설정)는 `.obsidian/plugins/memory-tracker/data.json`에 저장된다.
